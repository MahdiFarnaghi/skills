# Skills

A collection of [Claude Code](https://claude.com/claude-code) skills that extend Claude's capabilities with specialized knowledge and workflows.

## Skills

### anki-creator
Create structured Anki flashcard decks from vocabulary lists. Generates CSV files with definitions, examples, translations, synonyms, antonyms, and grammatical information. Supports any language.

**Usage:** Provide a vocabulary list and get a CSV file ready for Anki import.

## Installation

1. Copy the skill directory to `~/.claude/skills/`
2. Or install `.skill` files directly via Claude Code
