# Orchestration plan packet

Use for Standard and Safety-critical work, and whenever dependency or sequencing risk exists.

Include the objective, confirmed orchestrator execution profile, workflow
profile, invariants, non-goals, pair configuration, milestones, dependencies,
implementation/review alternation, integration strategy, verification tiers,
rollback or recovery needs, known uncertainties, and no more than three
directed questions. Name exact worktrees and path scopes at each write/review
boundary.

Terra should challenge whether each milestone is independently verifiable, whether ownership and transitions are explicit, whether any milestone relies on incomplete earlier behavior, and whether the pair has genuine reviewer independence. Freeze the plan after one correction round or escalate.
